# PowerBI-Store-Performance
Developed an interactive Power BI dashboard to analyze retail store performance based on sales trends, promotional effectiveness, and regional revenue distribution.
The project focused on identifying high-performing and underperforming stores using KPIs such as total revenue, transaction count, average sales, and store ranking. Created dynamic visualizations including heatmaps, treemaps, and gauge charts to monitor business performance, compare promotional impact, and support data-driven decision-making through filters and slicers.
